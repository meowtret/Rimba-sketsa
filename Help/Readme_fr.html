Plugin QdrawEVT :

Ce plugin est dérivé de l'outil qdraw (ce plugin n’est plus maintenu) et intègre avec de grosses améliorations les fonctions de sélection de qgeric (ce plugin n’est plus maintenu).

Utilisation avec un projet standard :

Les icônes deviennent bleues à leur première utilisation, et le restent le temps de la session QGIS.

Les objets dessinés se créent dans un groupe « Dessins ».

Tous les outils de dessin et de sélection sont utilisables, la sélection finale est optionnelle et liée à un choix de l’utilisateur.

Une sélection n’est possible que par groupe de couches. Si le projet en cours ne comprend aucun groupe et qu’une sélection a été demandée, l’utilisateur sera invité à choisir un nom pour le groupe, celui-ci sera créé dans la fenêtre des couches et l’utilisateur sera invité à choisir les couches à y placer par cochage dans la liste qui lui est présentée.

Utilisation en gestion de crise :

Transformation d’un projet standard en projet Gestion de crise :

Avec le bouton Paramètres de la barre d’outils QdrawEVT, affichez la fenêtre de paramétrage et cliquez sur « Créer le groupe et les couches d’évènements ».

Un groupe « Evenements » sera automatiquement ajouté au projet ouvert en cours, ainsi que trois couches spécifiques : point, ligne et polygone.

C’est la présence de ce groupe qui définit le maintien en rouge de la couleur des icônes de l’outil à l’utilisation.

Les évènements seront enregistrés selon leur géométrie dans les couches évènement contenues dans le groupe, et celles-ci seront automatiquement mises en lecture seule.

Une fois un item créé, il n’est pas effaçable. Pour parer au problème d'une possible erreur de création, les couches sont munies d’une analyse thématique intégrée, qui permet ainsi de décocher un éventuel objet géographique erroné.

La mise en forme par fichier de style QML des trois couches placées dans le groupe évènement est fournie par le plugin.

Cette fonctionnalité transforme ainsi ces trois couches en une véritable main-courante des actions effectuées avec le plugin, tout étant automatiquement horodaté et identifié.

Seront aussi créés les groupes principaux conditionnant le fonctionnement :

Enjeux : destiné à recevoir toutes les couches définissant des enjeux, pouvant être placées en sous-groupes.

Aléas/Risques : destiné à recevoir toutes les couches définissant des aléas ou des risques.

RDI : destiné à recevoir toutes les couches spécifiques aux RDI. Peuvent être en doublon avec des couches du groupe Enjeux.

Administratif : destiné à recevoir toutes les couches définissant des contours administratifs (communes, EPCI, etc.) ou couches référentielles.

Fonds de plan : destiné à recevoir toutes les couches référentielles à majorité raster.

Il vous appartiendra ensuite d’y répartir les couches selon vos besoins.

Remarque importante : tous les groupes et couches contenus dans les groupes Enjeux, RDI et Aléas/Risques doivent être cochés par défaut. Les trois groupes Enjeux, RDI et Aléas/Risques doivent être eux-mêmes décochés par défaut.

Là aussi, une sélection n’est possible que par groupe de couches.

Attention : ne seront présentés au choix de l’utilisateur pour la sélection que les groupes principaux décochés dans la fenêtre des couches.

Aucune manipulation dans la fenêtre des couches n'est nécessaire, tout est automatisé par le système des groupes définis par le plugin.

Le résultat d’une sélection est présenté dans une fenêtre spécifique, entièrement autonome, par un système de barre d’outils intégré pour l’exportation de tableaux de données ou pour l’affichage des extraits de couches concernées dans la fenêtre carte.

Tous les extraits de couches contenus dans la fenêtre de sélection sont conformes aux configurations des couches d’origine : toutes les mises en forme, jointures, paramétrage de l’affichage des attributs, actions et autres macros éventuelles sont intégralement reprises et fonctionnelles sur les exportations dans la fenêtre carte.

TRÈS IMPORTANT : les exportations d’extraits de couches se faisant en couches mémoire, l’installation et l’activation du plugin MemoryLayerSaver est obligatoire pour la conservation dans le projet.

Plugin Gestion_crise :

Le plugin QdrawEVT donne la possibilité d'installer un plugin annexe nommé « Gestion_crise ».

La commande d’installation se trouve dans le menu « Extension → QdrawEVT → Installer le plugin Gestion de crise ».

Ce plugin comprend le projet complet utilisé en DDT04. Les chemins des fichiers utilisés dans ce projet sont ceux de la géobase, couramment utilisée en DDT/DDTM.

Il sera nécessaire de l'adapter à votre structure.

Les paramètres de lettre de lecteur réseau, les adresses IP des serveurs et les dossiers partagés sont paramétrables dans le menu « Extension → Gestion de crise → Configurer les partages réseau ».

La configuration fournie par défaut dans le plugin est celle utilisée en DDT04.

Ce plugin permet l'utilisation d'un disque externe en support de données, ce qui rend l'utilisation en totale autonomie, même en l'absence de toute connexion réseau et/ou Internet.

Il sera nécessaire pour cela de définir la même arborescence sur le disque externe que celle utilisée pour le paramétrage des partages réseau.

La connexion à un disque externe conforme ou au réseau interne est entièrement automatique.

Après une connexion conforme, une fenêtre de choix d’action est présentée à l’utilisateur afin de choisir l’opération à effectuer : Exercice, Entrainement, Crise réelle.

Important : Une fois l'extension Gestion de crise installée par le menu Extensions/QdrawEVT/Installer le plugin Gestion de crise, les lettres de lecteur réseau et les chemins seront entièrement configurables par le menu Extensions/Gestion de crise/Configurer les partages réseau.

Si un disque dur est configuré avec les mêmes chemins racine que ceux définis dans cette partie, le disque sera connecté comme un réseau autonome de manière transparente. Par exemple, si un lecteur réseau est configuré avec la lettre R: pointant sur 10.4.8.xxx/gbref et qu'un dossier gbref est présent sur le disque, le contenu de ce dossier sera accessible par la même lettre R:.

Cela permet de travailler en totale autonomie, même en l'absence de toute connexion internet, VPN et/ou réseau connecté.

Choix Exercice : un dossier horodaté sera créé dans le dossier « Exercices » du support en cours d’utilisation, réseau interne ou disque externe.

Choix Crise réelle : un dossier horodaté sera créé dans le dossier « Evenements » du support en cours d’utilisation, réseau interne ou disque externe.

Choix Entrainement : un dossier horodaté sera créé dans le dossier « Formation » sur le bureau de l’utilisateur en cours.

Là aussi, aucune intervention de l’utilisateur n’est nécessaire, tout est automatisé.
