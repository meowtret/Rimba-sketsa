Rimba Sketsa

Quick drawing and selection tools for QGIS. Version 1.0.0

Toolbar tools

ToolHow to use
TextLeft click on the map and type the text. It is stored as a label on a layer in the Drawings group.
PointLeft click on the map. The small arrow next to the icon offers:
• XY: type X/Y coordinates and choose their projection (WGS 84 by default).
• DMS: type latitude/longitude in degrees-minutes-seconds.
LineLeft click to add vertices, right click to finish.
RectangleHold the left button and drag. A single click asks for a size (metres).
CircleHold the left button and drag from the centre. A single click asks for a radius (metres).
PolygonLeft click to add vertices, right click to finish.
BufferSelect a vector layer in the Layers panel, then click a feature on the map. Choose Create buffer (distance in metres) or No buffer (use the feature itself).
The second option under the small arrow: draw a polygon; every feature of the selected layer it intersects becomes the buffer source.
SettingsDrawing colour and opacity, text font and colour.

Where drawings go

Each drawing gets a name and is stored as a memory layer in the Drawings group (top of the Layers panel). Tick Add to an existing layer to put the drawing into another layer with the same geometry type.

Memory layers are lost when QGIS closes; right click the layer → Make Permanent / Export to keep it.

Selecting features inside a drawing

After a line, rectangle, circle, polygon or buffer is drawn, the plugin offers a selection. If you answer Yes:

  1. Choose the layer group to search. Checked groups are used directly; otherwise a list of groups is shown.
  2. Features of visible vector layers that intersect the drawing are selected.
  3. Results open in a table window, one tab per layer.

These groups are never searched (case, spaces and accents are ignored): Peta Dasar, Basemap, Administrasi, Fonds de plan, Administratif, and the Drawings group itself.

Results window

  • Save this tab / Save all results: write an ODS spreadsheet (opens in LibreOffice or Excel).
  • Export as memory layer: turn the selection into a new layer.
  • Zoom to selected attributes and Highlight geometry / centroid: click rows to see the features on the map.
  • The status bar shows the number of selected features and their area (polygons) or length (lines).

Notes

  • Buffer, radius and rectangle sizes are in metres; use a projected, metric project CRS (e.g. UTM).
  • The interface language follows QGIS (Settings → Options → General → User interface translation).
