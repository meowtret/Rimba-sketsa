Rimba Sketsa

Alat gambar dan seleksi cepat untuk QGIS. Versi 1.0.0

Alat di toolbar

AlatCara pakai
TeksKlik kiri di peta, lalu ketik teksnya. Teks disimpan sebagai label pada layer di grup Sketsa.
TitikKlik kiri di peta. Panah kecil di sebelah ikon membuka dua pilihan:
• XY: isi koordinat X/Y lalu pilih proyeksinya (default WGS 84).
• DMS: isi lintang/bujur dalam derajat-menit-detik.
GarisKlik kiri untuk menambah titik, klik kanan untuk selesai.
PersegiTahan klik kiri lalu seret. Klik sekali untuk mengisi ukuran (meter).
LingkaranTahan klik kiri lalu seret dari titik pusat. Klik sekali untuk mengisi jari-jari (meter).
PoligonKlik kiri untuk menambah titik, klik kanan untuk selesai.
BufferPilih layer vektor di panel Layers, lalu klik objek di peta. Pilih Buat buffer (isi jarak dalam meter) atau Tanpa buffer (memakai objek itu sendiri).
Pilihan kedua di panah kecil: gambar poligon, lalu semua objek layer terpilih yang terpotong poligon dipakai sebagai dasar buffer.
PengaturanWarna dan opasitas gambar, huruf dan warna teks.

Menyimpan gambar

Setiap gambar diberi nama, lalu disimpan sebagai layer memori di grup Sketsa (paling atas di panel Layers). Centang Tambahkan ke layer yang sudah ada untuk memasukkan gambar ke layer lain yang jenis geometrinya sama.

Layer memori hilang saat QGIS ditutup. Kalau perlu disimpan, klik kanan layer, lalu Make Permanent / Export.

Seleksi objek di dalam gambar

Setelah garis, persegi, lingkaran, poligon, atau buffer selesai dibuat, plugin menawarkan seleksi. Kalau dijawab Ya:

  1. Pilih grup layer yang ingin diseleksi. Grup yang dicentang langsung dipakai. Kalau belum ada yang dicentang, plugin menampilkan daftar grup.
  2. Objek pada layer vektor yang tampil dan berpotongan dengan gambar akan terseleksi.
  3. Hasilnya muncul di jendela tabel, satu tab per layer.

Grup berikut otomatis tidak ikut diseleksi (penulisan huruf besar/kecil, spasi, dan aksen diabaikan): Peta Dasar, Basemap, Administrasi, Fonds de plan, Administratif, serta grup Sketsa itu sendiri.

Jendela hasil seleksi

  • Simpan hasil tab ini / Simpan semua hasil: simpan ke file spreadsheet ODS (bisa dibuka di LibreOffice atau Excel).
  • Ekspor ke layer memori: hasil seleksi menjadi layer baru.
  • Zoom ke baris terpilih dan Sorot geometri / titik tengah: klik baris di tabel untuk melihat objeknya di peta.
  • Status bar menampilkan jumlah objek terpilih, luas (poligon), atau panjang (garis).

Catatan

  • Ukuran buffer, jari-jari, dan persegi dalam meter, jadi proyek sebaiknya memakai CRS bersatuan meter (mis. UTM / EPSG:32750, EPSG:32751).
  • Bahasa antarmuka mengikuti bahasa QGIS (Settings → Options → General → User interface translation).
